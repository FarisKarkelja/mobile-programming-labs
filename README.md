## Description
This repository contains lab exercises for the Introduction to Mobile Programming course. Each lab explores core programming concepts and language features relevant to mobile app development, implemented and tested outside a full mobile app project structure.

## Languages and Technologies Used
- Kotlin
- Java
- IntelliJ IDEA

## Features
1. **Language Fundamentals:**
   - Kotlin syntax, types, and control flow
   - Interoperability between Kotlin and Java
2. **Lab-Based Structure:**
   - Each lab is self-contained and organized under `src`
   - Dedicated `test` source folder for verifying lab solutions

## Installation
No installation is required to run these labs. Simply clone the repository and open the project folder in **IntelliJ IDEA**.
```bash
git clone https://github.com/FarisKarkelja/mobile-programming-labs.git
```

## Usage
Open the project in IntelliJ IDEA, let it resolve the Kotlin runtime dependency, and run individual lab files from the `src` folder as needed.
